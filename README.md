# 🛣️ Smart Toll Management System
A full-stack application for automated FASTag toll collection and revenue management.

## 🚀 Features
- **Dual Dashboard**: Separate views for Toll Operators and Vehicle Owners.
- **Dynamic Pricing**: Automatic toll calculation based on vehicle type.
- **Live Feed**: Real-time traffic logging with CSS animations.
- **Wallet Management**: FASTag recharge and transaction history.

## 🛠️ Tech Stack
- **Frontend**: React.js, CSS3 (Animations/Glassmorphism)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas (Cloud)
- **Deployment**: Render & GitHub (CI/CD)

## 📖 Setup Instructions
1. Clone the repository.
2. Run `npm install` in the `Server` and `client` folders.
3. Add your `MONGO_URI` to a `.env` file in the `Server` folder.
4. Run `node index.js` in the Server and `npm start` in the Client.
